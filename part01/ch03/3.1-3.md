# Exercise 3.1-3

Explain why the statement, "The running time of algorithm $A$ is at least $O(n^2)$," is meaningless.

# Answer

Because, Big-O notation describes an **upper bound** on growth. So saying **"at least"** would mean "**running time $\ge C * n^2$** for come constant $C$ and large n", but $O(n^2)$ denotes a set of functions, so the phrasing is incoherent.

By the way, this one should use $\Omega$ because this is the correct statement for a lower bound.
