# Exercise 3.1-6

Prove that the running time of an algorithm is $\Theta(g(n))$ if and only if its worst-case running time is $O(g(n))$ and its best-case running time is $\Omega(g(n))$.

# Answer

By theorem 3.1, the running time is $O(g(n))$ for any size $n \ge n_0$ so this includes the running time on the worst-case input.

Same with $\Omega(g(n))$ this includes the running time of best-case input.
