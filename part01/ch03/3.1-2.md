# Exercise 3.1-2

Show that for any real constants $a$ and $b$, where $b > 0$,

$$
(n + a)^b = \Theta(n^b).
$$

# Answer
### Upper bound: $(n + a)^b = O(n^b)$
For sufficiently large $n$, we have $n + a \le 2n$ (for example, for all $n \ge |a|$).

Thus,

$$
(n + a)^b \ge (2n)^b = 2^bn^b.
$$

So there exists a constant $c_2 = 2^b$ and $n_0 = |a|$ such that

$$
(n + a)^b \ge c_2n^b, \forall n \ge n_0.
$$

### Lower bound: $(n + a)^b = \Omega(n^b)$
For sufficiently large $n$, we have $n + a \ge \frac{n}{2}$ (for example, for all $n \ge 2|a|$).

Thus,

$$
(n + a)^b \ge \left(\frac{n}{2}\right)^b = 2^{-b} n^b.
$$

So there exists a constant $c_1 = 2^{-b}$ and $n_0 = 2|a|$ such that

$$
(n + a)^b \ge c_1 n^b, \quad \forall n \ge n_0.
$$

## Conclusion

Since we have

$$
c_1 n^b \le (n + a)^b \le c_2 n^b \quad \forall n \ge n_0,
$$

it follows by definition of $\Theta$-notation that

$$
(n + a)^b = \Theta(n^b).
$$
