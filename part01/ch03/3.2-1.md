# Exercise 3.2-1
Show that if $f(n)$ and $g(n)$ are monotonically increasing functions, then so are
the functions $f(n) + g(n)$ and $f(g(n))$, and if $f(n)$ and $g(n)$ are in addition
nonnegative, then $f(n) \times g(n)$ is monotonically increasing.

# Answer

We have: $f(n)$ and $g(n)$ are nonnegative function.

So these result are positive numbers.

Then $f + g, \ f(g(n)), \ f \times g$ are monotonically increasing.
