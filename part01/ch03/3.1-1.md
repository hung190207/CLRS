# Exercise 3.1-1

Let $f(n)$ and $g(n)$ be asymptotically nonnegative functions. Using the basic definition of $\Theta$-notation, prove
that max($f(n),g(n)$) $= \Theta(f(n) + g(n)).$

# Answer

Let $f(n)$ and $g(n)$ be asymptotically nonnegative, i.e. $\exists N$ such that for all $n$ &ge; $N$ we have $f(n)$
&ge; $0$ and $g(n)$ &ge; $0$. Define

$$
h(n) := \max\{f(n),g(n)\}, \quad S(n) := f(n) + g(n).
$$

For $n$ &ge; $N$ we have two easy inequalities:

1. Upper bound: since $f \ $, $ \ g$ &ge; $0$,

$$
h(n) = \max\{f(n),g(n)\} \le f(n) + g(n) = S(n).
$$

2. Lower bound: let $x = h(n)$. Then both $f(n) \le x$ and $g(n) \le x$, so

$$
f(n) + g(n) \le x + x = 2x. \;\Longrightarrow\; \frac{1}{2}S(n) \le x = h(n).
$$

Thus for all $n$ &ge; $N$,

$$
\frac{1}{2}S(n) \le h(n) \le 1 * S(n).
$$

This is exactly the definition of $h(n) = \Theta(S(n))$. Therefore

$$
\max\{f(n),g(n)\} = \Theta(f(n) + g(n)).$$
