# Exercise 3.1-5

Prove Theorem 3.1

# About Theorem 3.1:
It says: **"For any two function $f(n)$ and $g(n)$, we have $f(n) = \Theta(g(n))$ if and only if $f(n) = O(g(n))$ and $f(n) = \Omega(g(n))$"**.

# Answer

Assume $f(n) = \Theta(g(n))$. By definition of $\Theta$ there exist positive constant $c_1, c_2$ and $n_0$ such that for all $n \ge n_0$,

$$
0 \le c_1g(n) \le f(n) \le c_2g(n)
$$

From $f(n) \le c_2g(n)$ we have $f(n) = O(g(n))$. From $c_1g(n) \le f(n)$ we get $f(n) = \Omega(g(n))$. Thus both hold.

So with $f(n) = O(g(n))$ and $f(n) = \Omega(g(n))$. Then there exist positive constant $c_2, n_1$ such that for all $n \ge n_1$,

$$
f(n) \le c_2g(n),
$$

and positive constants $c_1, n_2$ such that for all $n \ge n_2$,

$$
f(n) \ge c_1g(n).
$$

Let $n_0 = \max\{n_1,n_2\} $. For every $n \ge n_0$ both inequalities hold simultaneously, so

$$
0 \le c_1g(n) \le f(n) \le c_2g(n).
$$

By definition this means $f(n) = \Theta(g(n))$.
