# Exercise 1.1-4

How are the shortest-path and traveling-salesman problems given above similar?
How are they different?

# Answer

First of all, both they are use graphs and try to minimize distance, they also appear in real-world routing

Then about different, goal is the first different.

**Shortest Path Problem:**

- Find the **shortest path between two specific nodes**.
- Example: shortest way from __A &rarr; B__.

Traveling Salesman Problem (TSP):

- Visit **every node exactly once** and return to the starting point.
- Example: start at city A &rarr; visit all cities &rarr; return to A.

Next, complexity is different

**Shortest Path**

- Can be solved efficiently in polynomial time.
- Works fast even with millions of nodes.

**TSP**

- NP-hard problem.
- No known fast algorithm for exact solution.
- Very expensive to solve exactly as number of cities grows.

Last, use cases differ

**Shortest Path Example**

- Find the quickest driving route from your home to school.

**TSP Example**

- A delivery truck must visit **every house** on its list exactly once.
