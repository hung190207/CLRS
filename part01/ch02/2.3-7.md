# Exercise 2.3-7

Describe a $\Theta(n\ \lg\ n)$-time algorithm that, given a set $S$ of $n$ integers and another
integer $x$, determines whether or not there exist two elements in $S$ whose sum is
exactly $x$.

But now we just want to know is array $S$ have target sum (`x`) so we change the function a little bit.

### Pseudocode:

```java
import java.util.Arrays;

public boolean twoSum(int[] S, int x) {
    Arrays.sort(S);
    int i = 0;
    int j = S.length - 1;
    while (i < j) {
        int sum = S[i] + S[j];
        if (sum == x) return true;
        else if (sum < x) i++;
        else j--;
    }
    return false;
}
```

### Complexity:
- Sorting: $\Theta(n\ \log\ n)$
- Two pointers: $\Theta(n)$
- Summary: $\Theta(n\ \log\ n)$
