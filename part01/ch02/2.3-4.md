# Exercise 2.3-4

We can express insertion sort as a recursive procedure as follows. In order to sort
*A*[0..*n*], we recursively sort *A*[0 ... n-1] and then insert *A*[*n*] into the sorted array
*A*[0..*n* - 1]. Write a recurrence for the worst-case running time of this recursive
version of insertion sort.

# Answer

Let $T(n)$ be the worst-case running time to sort an array of $n$ elements (so $n$ = number of elements)

When we sort recursively we do:

- cost $T(n - 1)$ to sort the first $n - 1$ elements, and
- in the worst case, $\Theta(n)$ to insert the $n$-th element into the sorted prefix (shifting up to $n - 1$ elements).

A convenient recurrence is therefore

$$
T(n) = T(n - 1) + \Theta(n), \ T(1) = \Theta(1).
$$

Unrolling or summing gives

$$
T(n) = \Theta(1) + \sum_{k=2}^{n}\Theta(k) = \Theta(\sum_{k=1}^{n}k) = \Theta(n^2).
$$

So the worst-case running time of the recursive insertion sort is

$$\boxed{
T(n) = T(n - 1) + \Theta(n) \ with \ T(1) = \Theta(1)
}$$

, which solves to $\Theta(n^2)$.
