# Exercise 2.2-4

How can we modify almost any algorithm to have a good best=case running time?

# Answer

#### We add a quick check at the beginning that detects an "easy" case and returns immediately.

This is called a **best-case optimization** or **early-out condition**.

## Explanation

Many algorithms run slowly because they must process all the input.

But the *best-case* running time only depends on whether there exists **any** situation where the algorithm can finish quickly.

So if we add a check like:
- "Is the input already sorted?"
- "Is the array empty?"
- "Is the answer obviously trivial?"

then whenever that condition is true, the algorithm can stop immediately in

$$
\Theta(1)
$$

time.
Thus, the best-case becomes very good.
