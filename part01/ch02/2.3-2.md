# Exercise 2.3-2

Rewrite the $MERGE$ procedure so that it does not use sentinels, instead stopping
once either array $L$ or $R$ has had all its elements copied back to $A$ and then copying
the remainder of the other array back into $A$.

# Answer

## $MERGE$ Sample code:

```java
public static int[] merge(int[] A, int p, int q, int r) {
    int n1 = q - p + 1;
    int n2 = r - q;
    int[] L = new int[n1 + 1];
    int[] R = new int[n2 + 1];

    for (int i = 1; i <= n1; i++) {
        L[i] = A[p + i - 1];
    }

    for (int j = 1; j <= n2; j++) {
        R[j] = A[q + j];
    }

    L[n1 + 1] = Integer.MAX_VALUE;
//            to infinity
    R[n2 + 1] = Integer.MAX_VALUE;

    int i = 1;
    int j = 1;

    for (int k = p; k <= r; k++) {
        if (L[i] <= R[j]) {
            A[k] = L[i];
            i++;
        } else {
            A[k] = R[j];
            j++;
        }
    }
    return A;
}
```

So to change the $MERGE$ procedure to not using sentinels, but to copy all elements from $L$ and $R$, we add some conditions to make it terminates when **merge** all elements.

