# Exercise 2.2-3

Consider linear search again (see Exercise 2.1-3). How many elements of the input sequence need to be checked on the average, assuming that the element being
searched for is equally likely to be any element in the array? How about in the
worst case? What are the average-case and worst-case running times of linear
search in ‚$\Theta$-notation? Justify your answers.

# Answer

**Assumption:** the searched-for element *is in the array* and is equally likely to be at any of the *n* positions.

#### 1) How many elements are checked on average?
If the target is at position $i$ we check $i$ elements. Each position is equally likely with probalility *1*$/n$. So the expected number of checks is

$$
E[checks] = \sum_{i=1}^{n} i . \frac{1}{n} = \frac{1}{n} . \frac{n(n + 1)}{2} = \frac{n + 1}{2}
$$

So on average we check $\frac{n + 1}{2}$ elements.

#### 2) Worst case

In the worst case the element is in the last position, so we check *n* elements.

(If the element might **not** be present, the worst case is also *n* checks; the average depends on the probability of presence and is a different calculation.)


#### 3) Running times ($\Theta$-notation)

- Average-case: $\frac{n + 1}{2} = \Theta(n)$
- Worst-case: $n = \Theta(n)$

**Reason:** both $(n + 1)/2)$ and $n$ grow linearly with $n$, so up to constant factors the running time is linear.

*(For completeness: the best case is checking 1 element, i.e.* $\Theta(1)$ *)*.
