# Exercise 2.2-1

Express the function *n*<sup>3</sup> /1000 - 100*n*<sup>2</sup> + 100*n* + 3 in terms of $\Theta$-notation.
## About $\Theta$(Theta)-notation:
Theta notation is used in algorithm analysis (like in this book) to describe **asymptotic tight bounds**.

### Formal meaning

$$
f(n) = \Theta(g(n))
$$

means that *for large n*, $f(n)$ is bounded both above and below by $g(n)$, up to constant factors.

In other words:
$$
c_1 g(n) \le f(n) \le c_2 g(n)
\quad \text{for all sufficiently large } n
$$

So $\Theta$-notation gives:
- **upper bound** (like Big-O)
- **lower bound** (like Big-$\Omega$)
- **and both are tight**

# Answer
### Express:
$$
f(n) = \frac{n^3}{1000} - 100n^2 + 100n + 3
$$

in $\Theta$-notation

We look for the **dominant term** as $n$ &rarr; $\infty$.
- $\frac{n^3}{1000}$ grows like $n^3$
- $-100n^2$, $100n$, and $3$ grow slower.

So the function behaves like $n^3$ for large $n$.

**Therefore:**

$$\boxed{
f(n) = \Theta(n^3)
}$$

Constants (such as **1/1000**, 100, 3) do **not** affect $\Theta$-notation.
