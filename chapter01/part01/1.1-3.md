# Exercise 1.1-3

Select a data structure that you have seen previously, and discuss its strengths and limitations

# Answer

I choose array then an array is a data structure that stores a fixed number of elements of the same type in a continuous block of memory
that is its strength

About limitation, if you create an array with any size, the size cannot change again.
Then if you want to insert or remove an element in any positions of array, you must shift many elements.

There are many strengths and limitations of this data structure, but I just listed some examples.
