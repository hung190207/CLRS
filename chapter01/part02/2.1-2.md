`# Exercise 2.1-2

Rewrite the INSERTION-SORT procedure to sort into nonincreasing instead of nondecreasing order.

# Answer

### Sample code of nondecreasing sort:

```java
public int[] insertionSort(int[] arr) {
    for (int j = 1; j < arr.length; j++) {
        int key = arr[j];
        int i = j - 1;
        while (i > 0 && arr[i] > key) {
            arr[i + 1] = arr[i];
            i--;
        }
        arr[i + 1] = key;
    }
    return arr;
}
````

To change the sort from nondecreasing to nonincreasing we just need to change the condition in `while loop`.

Change `arr[i] > key` to `arr[i] < key`.
