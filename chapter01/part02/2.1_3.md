# Exercise 2.1-3

Consider the **searching problem**:

**Input**: A sequence of *n* numbers *A* = {*a<sub>1</sub>*,*a<sub>2</sub>*,....,*a<sub>n</sub>*} and a value *v*.

**Output**: An index *i* such that *v* = *A*[*i*] or the special value NIL if *v* does not
appear in *A*.

Write pseudocode for **linear search**, which scans through the sequence, looking
for *v*. Using a loop invariant, prove that your algorithm is correct. Make sure that
your loop invariant fulfills the three necessary properties.

## About loop invariant

We use loop invariants to help us understand why an algorithm is correct. We
must show three things about a loop invariant:

**Initialization**: It is true prior to the first iteration of the loop.

**Maintenance**: If it is true before an iteration of the loop, it remains true before the
next iteration.

**Termination**: When the loop terminates, the invariant gives us a useful property
that helps show that the algorithm is correct.

# Answer

## Linear Search - Pseudocode

```java
public int linearSearch(int[] arr, int target) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == target) {
            return i;
        }
    }
    return -1;
}
```

## Using Invariant Proof of Correctness

We analyze the `for loop`:

```text
for(int i = 0; i < arr.length; i++)
```

## Loop invariant

    At the start of each iteration of the loop (before checking arr[i]), the value target does not appear in the subarray
    arr[0 ... i-1].

In other words, up to the element just before the current index, target has not been found.

### 1. Initialization

Before the first iteration, *i = 0*, so the subarray is:

- arr[0 ... i-1] = arr[0 ... -1], which is an empty subarray.

The invariant holds because target cannot appear in an empty array.

### 2. Maintenance

Assume the invariant is true for the start of iteration i:

- target does NOT appear in arr[0 ... i-1].

During iteration i, there are two possibilities.

#### Case 1: arr[i] = target

- Then the algorithm returns i, which is correct, because we have found the first position where target appears.

#### Case 2: arr[i] $\neq$ target

- Then target does not appear in arr[0 ... i], because:
    - by the invariant, it is not in arr[0 ... i - 1],
    - and now we know it is not in arr[i].

Thus, the invariant will be true at the start of the next iteration i+1.

So the invariant is maintained.

### 3. Termination

The loop finishes when i = arr.length + 1.

At this point, by the invariant, target is **not** in arr[0 ... arr.length].

But arr[0 ... arr.length] is the entire array arr.

Thus, target does not appear anywhere in arr, so returning `-1` is correct.
