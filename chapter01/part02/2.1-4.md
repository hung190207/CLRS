# Exercise 2.1-4

Consider the problem of adding two *n*-bit binary integers, stored in two *n*-element
arrays *A* and *B*. The sum of the two integers should be stored in binary form in an (*n* + 1)-element array *C*. State
the
problem formally and write pseudocode for
adding the two integers.

# Answer

## Formal Problem Statement

**Input:**

Two *n*-bit binary integers, each stored in an *n*-element array:

- A = A[0 ... n]
- B = B[0 ... n]

Each A[i] and B[i] is either 0 or 1.
The least significant bit (LSB) is at index *n*.

**Output:**

An *(n + 1)*-element array **C = C[0 ... n+1]** representing the sum:

$$
C = A + B
$$

in binary.

C[0] is the most significant bit (possible carry), and C[n+1] is the least significant bit.

## Pseudocode: Binary Addition

```java
public int[] binaryAdd(int[] a, int[] b) {
    int n = a.length;
    int[] c = new int[n + 1];
    int carry = 0;

    for (int i = n - 1; i >= 0; i--) {
        int sum = a[i] + b[i] + carry;
        c[i + 1] = sum % 2;
        carry = sum / 2;
    }
    c[0] = carry;
    return c;
}
```

### Explanation
- We iterate from right to left (the least significant bit &rarr; most significant bit).
- At each bit position:
    - `sum` is either 0, 1, 2 or 3.
    - `sum mod 2` gives the output bit.
    - `sum / 2` gives the carry (0 or 1).
- After finishing, the final carry (0 or 1) become C[0], the new most significant bit.

### For example:
A = 1 0 1 1

B = 0 1 0 1

(n = 4)

Result C = 1 0 0 0 0 (since 11 + 5 = 16 in decimal &rarr; binary 10000)
